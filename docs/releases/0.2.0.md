# NovaSource G6 Config 0.2.0 — first release

Designated the application's first release on September 7, 2026, when Sprint 2
closed. Awaiting initial user feedback before further changes. The already
published packages retain their original test-release notes and self-signed
signatures; this designation does not replace their files or checksums.

Sprint 2 UI, connection reliability, and distribution updates.

- Manual connection with the last successful COM port preselected.
- Persistent main-window placement, monitor-aware dialogs, and refined layouts.
- One-second RF output and PLL lock polling with serialized device operations.
- Buffered serial replies and bounded connection retries; sweep stop completes
  an in-flight frequency command before stopping.
- Targeted dialog readbacks instead of full configuration reads on every close.
- Friendlier connection errors with a separate Technical details dialog.
- About, hardware overview, GPL license viewer, and manual update-page link.
- .NET 8 target with major runtime roll-forward.
- Windows x64 per-user installer, installation-free ZIP, and corresponding source.

## Validation and limitations

Release application build: no warnings or errors. All 59 automated tests passed
on the project-local .NET 10 runtime for this packaging run. Earlier runs of the
same suite also passed on system .NET 8.0.30 and .NET 9.0.19.

These are early test packages signed with a self-signed certificate, not a
publicly trusted signing identity. Windows may display publisher warnings.
No real-device acceptance or clean-machine installer acceptance was performed
for this release. Multi-monitor/DPI behavior still needs user acceptance.

Requires Windows 11 and a compatible x64 .NET Desktop Runtime (8 or newer).
Installer runtime guidance opens Microsoft's download page if needed.
Close the application normally before upgrading. Preferences are preserved.
Download the complete ZIP when using the installation-free option; extracting
only the EXE is insufficient. The ZIP still stores preferences in AppData.

GPL-3.0-or-later software; corresponding source is supplied alongside the binary
downloads. Manufacturer material and dependencies retain their own notices.
