About this test release

The application and installer use a self-signed test certificate. Windows does not automatically trust this certificate and may show publisher or SmartScreen warnings. Do not install the supplied certificate into Trusted Roots.

Before you start

  • Windows 11, with a compatible x64 .NET Desktop Runtime 8 or newer. A .NET SDK is not needed.
  • If needed, install .NET 10 Desktop Runtime for Windows x64. The runtime installer may request administrator permission.
  • A serial connection to your G6. Serial-adapter drivers and optional bridge software are installed separately.

Install and update

  1. Close G6 Config normally before installing or replacing files, including stopping any sweep.
  2. Run Setup, or extract the complete ZIP into a new folder.
  3. Launch the utility, select the correct COM port, and click Connect.

Preferences are preserved in %LOCALAPPDATA%\NovaSourceG6Config. The ZIP uses that same location; it is not a portable-settings mode. Updates do not install automatically.
